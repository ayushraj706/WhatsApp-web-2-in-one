# AI-Powered WhatsApp Web Clone SaaS

Production blueprint: Next.js frontend + Node/Express/Socket.io backend + Baileys (WhatsApp Web protocol)
+ PostgreSQL (chat/user data) + Redis (sessions/cache/rate-limit) + Capacitor (Android) + FCM (push).

## ⚠️ Important
- Baileys is an UNOFFICIAL WhatsApp Web library. Running this at scale as a SaaS violates WhatsApp's ToS
  and can get connected numbers banned. Use at your own legal/compliance risk. For a compliant product,
  migrate `backend/src/sockets/whatsappSocket.js` to the official WhatsApp Business Cloud API.
- "Anti-Delete" only re-displays messages that were already delivered to your server/device before the
  sender revoked them. No extra data is pulled from WhatsApp — this is why it's technically possible.

## Quick Start
```bash
cp .env.example backend/.env
cp .env.example frontend/.env.local
docker-compose up -d          # postgres + redis
cd backend && npm install && npm run dev
cd ../frontend && npm install && npm run dev
```
